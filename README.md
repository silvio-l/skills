# Skills

My personal Claude Code skill: a BSI/OWASP-aligned security audit for web backends.

Everything else that used to live in this repo has been retired in favour of
[`mattpocock/skills`](https://github.com/mattpocock/skills) (engineering process — grilling,
spec/ticket flow, TDD, code review, domain modelling) and
[`Code-with-Beto/skills`](https://github.com/Code-with-Beto/skills) (React Native / Expo
scaffolding). Install those upstream repos directly rather than looking for their equivalents
here.

## Quickstart

```bash
npx skills@latest add silvio-l/skills
```

## The skill

### `owasp-bsi-audit`

Security audit for PHP/Node web backends against the OWASP API Security Top 10 and the BSI
IT-Grundschutz web-application baseline (CON.8, CON.10, APP.3.1). See
[`skills/owasp-bsi-audit/SKILL.md`](./skills/owasp-bsi-audit/SKILL.md).
